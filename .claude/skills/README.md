# Скиллы проекта

Здесь лежат скиллы Claude Code для этого репозитория. Скилл — это папка с инструкцией,
которую Claude подгружает, когда задача подходит под описание скилла.

## Структура

Один скилл — одна папка. Имя папки становится именем скилла (`/имя-скилла`):

```
.claude/skills/
├── README.md              # этот файл
└── имя-скилла/
    ├── SKILL.md           # обязательный файл с инструкцией
    ├── references/        # опционально: большие справочные материалы
    └── scripts/           # опционально: вспомогательные скрипты
```

## Формат SKILL.md

В начале файла — YAML-фронтматтер, дальше обычный markdown с инструкцией:

```markdown
---
name: имя-скилла
description: Когда применять скилл и что он делает. Именно по этому тексту Claude решает, подгружать ли скилл, — пишите конкретно, с ключевыми словами из реальных запросов.
---

# Название скилла

## Когда использовать

Опишите ситуации, в которых скилл нужен, и те, в которых он не нужен.

## Как действовать

1. Первый шаг
2. Второй шаг

## Примеры

Хорошие и плохие варианты результата.
```

Требования к имени: строчные латинские буквы, цифры и дефисы, до 64 символов.
Имя папки и поле `name` должны совпадать.

## Правила

- **`description` важнее содержимого.** Скилл не сработает, если по описанию непонятно,
  когда он нужен. Пишите от триггеров: «Использовать, когда просят разобрать обращение
  студента…», а не «Скилл для обращений».
- **Один скилл — одна задача.** Лучше три узких скилла, чем один универсальный.
- **Держите SKILL.md коротким.** Объёмные справочники выносите в `references/`
  и ссылайтесь на них из инструкции — они подгрузятся только когда понадобятся.
- **Скиллы коммитятся в репозиторий**, поэтому доступны всем, кто с ним работает.

## Как создать скилл

Можно вручную по шаблону выше, можно попросить Claude — за это отвечает встроенный
скилл `skill-creator`, он же помогает улучшать описания уже существующих скиллов.

## Проверка

После добавления скилла перезапустите сессию Claude Code и убедитесь, что скилл виден
в списке доступных. Вызвать вручную можно через `/имя-скилла`.
