## MCP-серверы в облачных сессиях

Облачная сессия (claude.ai/code) читает список MCP-серверов из `.mcp.json` в
корне репозитория при старте сессии.

Токен в файл не пишем — файл лежит в git и утечёт вместе с репозиторием.
Вместо значения подставляется переменная окружения `GITHUB_MCP_PAT`, а сам
токен задаётся в настройках облачного окружения:
кнопка с названием окружения над полем ввода → настройки → раздел
`Environment variables` → строка `GITHUB_MCP_PAT=<токен>`.

Изменения в `.mcp.json` подхватываются только новой сессией.
