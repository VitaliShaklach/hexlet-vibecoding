# Калькулятор калорий

Веб-страница для расчёта суточной нормы калорий и баланса БЖУ.

## Запуск

Отдельная установка не нужна — откройте `index.html` в браузере:

```bash
xdg-open index.html    # Linux
open index.html        # macOS
```

Весь проект — один файл без внешних зависимостей.

## Что считает

| Показатель | Как получается |
| --- | --- |
| BMR | Формула Миффлина — Сан Жеора: `10 × вес + 6.25 × рост − 5 × возраст + k`, где `k = +5` для мужчин и `−161` для женщин |
| TDEE | BMR × коэффициент активности (1.2 … 1.9) |
| Норма под цель | TDEE × 0.8 (снижение веса), × 1.0 (удержание) или × 1.15 (набор массы) |
| Белки | 2.0 г/кг при снижении веса, 1.6 г/кг при удержании, 1.8 г/кг при наборе |
| Жиры | 25% калорийности |
| Углеводы | Остаток калорий после белков и жиров |
| ИМТ | Вес в килограммах, делённый на квадрат роста в метрах |
| Расход при нагрузке | `MET × 3.5 × вес(кг) ÷ 200 × минуты` — MET-значения из Compendium of Physical Activities |

При очень низкой калорийности на углеводы может не остаться места — тогда норма белка
снижается до 1.2 г/кг, чтобы сумма БЖУ сходилась с целевой калорийностью.

## Превью в мессенджерах

В `<head>` прописаны теги Open Graph и Twitter Card. Картинка превью — `og-preview.png`
в корне проекта, 1200×630.

Адреса в тегах абсолютные (`https://vitalishaklach.github.io/hexlet-vibecoding/...`), и это
обязательное условие: Телеграм, WhatsApp и соцсети запрашивают превью со своих серверов
и относительные пути не разрешают.

При смене домена нужно обновить `og:url`, `og:image`, `twitter:image` и `link rel="canonical"`.

Телеграм кеширует превью надолго. Чтобы он перечитал теги после изменений, отправьте ссылку
боту [@WebpageBot](https://t.me/WebpageBot) — он сбросит кеш.

## Разработка

Проверки, которые гоняет CI на каждый пул-реквест, запускаются и локально:

```bash
npm ci                  # установить зависимости
npm run lint:html       # валидация вёрстки (html-validate)
npx playwright install chromium
npm test                # браузерные тесты в Chromium
```

Тесты открывают `index.html` в браузере и проверяют то, что видит пользователь:
значения BMR и TDEE на контрольных профилях, сходимость суммы БЖУ с целевой
калорийностью, поведение при некорректном вводе и доступность с клавиатуры.
Конфигурация CI — `.github/workflows/ci.yml`.

## Тёмная и светлая тема

Кнопка в правом верхнем углу переключает тему. Выбор сохраняется в `localStorage`
и применяется при следующем заходе.

Логика трёхсостоянийная, хотя кнопка одна:

- пока пользователь не нажал кнопку, атрибута `data-theme` нет и страница следует
  системной настройке через `prefers-color-scheme`;
- первый клик записывает выбор в `data-theme` на `<html>` и в `localStorage`, и с этого
  момента он перекрывает системную настройку в обе стороны.

Тема применяется небольшим скриптом в `<head>` до отрисовки страницы — иначе при сохранённой
тёмной теме на мгновение мелькал бы белый фон. Все обращения к `localStorage` обёрнуты
в `try/catch`: в приватном режиме доступ к хранилищу может выбрасывать исключение, и тогда
переключатель просто работает без запоминания.

## Рекомендации по активности

Под результатом выводится карточка с тремя частями:

- расшифровка выбранного уровня активности конкретными примерами;
- рекомендация под цель, опирающаяся на норму ВОЗ — 150–300 минут умеренной активности
  в неделю плюс две силовые тренировки;
- таблица из десяти занятий с расходом за 30 минут, пересчитанным под введённый вес.

Расход от тренировок уже заложен в коэффициент активности, на который умножается BMR,
поэтому вычитать цифры из таблицы из суточной нормы повторно не нужно — об этом сказано
и в самом интерфейсе.

## Рекомендации при заболеваниях

В форме есть необязательное поле «Заболевание сердца или сосудов» с пятнадцатью диагнозами:
гипертония, ИБС и стенокардия, перенесённый инфаркт, хроническая сердечная недостаточность,
атеросклероз, мерцательная аритмия, варикоз, тромбофлебит, тромбоз глубоких вен,
перенесённый инсульт, кардиомиопатия, пороки клапанов, аневризма аорты, атеросклероз артерий
ног, метаболический синдром.

При выборе диагноза появляется карточка с рекомендациями по питанию, по физической активности
и отдельным блоком предостережений. Содержимое справочное и не влияет на расчёт калорий —
норма считается только по полу, возрасту, росту, весу, активности и цели.

Часть предостережений принципиальна для безопасности и покрыта тестами: например, при
тромбофлебите, тромбозе глубоких вен и мерцательной аритмии выводится предупреждение о том,
что при приёме варфарина нельзя резко менять количество зелени в рационе, поскольку витамин K
ослабляет действие препарата. Обычный совет «ешьте больше зелени» без этой оговорки для таких
пациентов опасен.

## Категории ИМТ

Классификация ВОЗ:

| ИМТ | Категория |
| --- | --- |
| до 18,5 | Недостаточный вес |
| 18,5 — 24,9 | Нормальный вес |
| 25,0 — 29,9 | Избыточный вес |
| 30,0 — 34,9 | Ожирение I степени |
| 35,0 — 39,9 | Ожирение II степени |
| 40,0 и выше | Ожирение III степени |

ИМТ не различает мышечную и жировую массу, поэтому у людей с развитой мускулатурой
показатель завышен.

## Ограничения ввода

Возраст 14–100 лет, рост 120–230 см, вес 30–300 кг. За пределами диапазона вместо
результата показывается сообщение об ошибке.

Расчёт справочный и не заменяет консультацию врача или диетолога. Рекомендации при
заболеваниях — общая информация, а не назначение: диету и допустимую нагрузку при любом
из перечисленных диагнозов определяет лечащий врач.
